# Compiler Construction — Lectures 1, 2 & 3 (2026 Edition)

Interactive course website by **Muhammad Tahir Mehmood** for BS Computer Science students.

- Lecture 1 — Introduction to Compiler Construction
- Lecture 2 — Organization & Basic Concepts
- Lecture 3 — Phases of a Compiler, Front End & Back End

Includes animations, a live tokenizer, parser and compiler demo, CPU simulator, quizzes, flashcards and a glossary. Progress and bookmarks are saved in the browser.

Single static file: open `index.html` in a browser, or deploy the repository to Vercel (no build step).
